# Архитектурные решения (ADR)

Использовать `ADR-TEMPLATE.md` для решений с настоящими альтернативами и долгосрочными последствиями. Имена файлов: `ADR-0001-short-slug.md`, `ADR-0002-...`.

Статусы: **proposed**, **accepted**, **superseded**, **rejected**. Переводить ADR в `accepted` только после явного согласия пользователя. Обязательно связывать решение с исследованием, рисками и влиянием на public API и миграции.

Пока не принято ни одного решения.
