# Текущее состояние архитектурного проекта

Обновлено: 2026-10-20.  
Фаза: **Discovery — интервью ещё не началось**.  
Разрешение на реализацию: **не предоставлено**.

## Цель
Спроектировать составную платформу .NET-микросервисов: Kafka, CQRS/message handling, DDD, gRPC, PostgreSQL, логирование/диагностика и удобное создание новых сервисов. Пользователь ожидает самостоятельного, критически мыслящего архитектора, который проводит интервью и исследование до ТЗ.

## Установленные факты
- Начинаем проектирование в **чистом репозитории Codex**.
- `Platform.AddKafka()`-подобный API — иллюстрация желаемого DX, а не обязательный контракт.
- Кандидаты на общие компоненты: Kafka publisher/consumer, handlers/CQRS, агрегаты и события DDD, gRPC, Postgres, Serilog.
- Агенту нужно предлагать дополнительные возможности, изучать альтернативы и способы избежать ненужного собственного кода.

## Утверждённые архитектурные решения
Нет. Ни один ADR не принят.

## Наиболее важные неизвестные
1. Характерные первый и второй сервисы; их потребители и масштаб.
2. Хостинг/deployment и локальный цикл разработки.
3. Способ распространения библиотек и количество команд/проектов.
4. Требуемые гарантии Kafka + PostgreSQL и политики восстановления.
5. Версии .NET, разрешённые зависимости, лицензии и ограничения совместимости.

## Первая исследовательская гипотеза
Проверить, не окажется ли комбинация стандартного .NET hosting/DI, отдельных пакетов, service defaults и шаблонов (возможно с использованием Aspire) проще и надёжнее универсального собственного builder. Результат пока неизвестен.

## Следующее действие (ровно одно)
Выполнить `prompts/START.md`: выдать первые 3–5 сильных вопросов, начальную карту возможностей и предварительные варианты; после ответов обновить документы.

## Порядок продолжения
В начале существенной сессии прочитать этот файл и связанные материалы. Согласованные решения отражать ссылками на ADR, отвеченные вопросы закрывать в `docs/discovery/question-backlog.md`, оставлять одно конкретное следующее действие. Не выдавать гипотезы за утверждённые решения.
